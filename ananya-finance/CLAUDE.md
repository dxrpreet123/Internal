# Ananya's Financial Management: standing design rules

These come from the owner. Follow them in every design and code change to this project.

1. **It's a website, not an app.** No app chrome of any kind: no bottom tab bar, no fixed or sticky navigation bars, no fake phone status bars, no icon tab rows.
2. **Really minimal.** Few elements per screen and generous space. Phones especially must never look cluttered.
3. **Front buttons only.** The front page shows the summary plus plain buttons that lead to each section (Budget, Plan, Growth, Ask). A section page has one "← Back" button at the top. There is no persistent navigation.
4. **Pink.** Pink is the colour of the site.
5. **Mobile first.** Design for a ~390px phone first, then widen for desktop.
6. **The chosen look is Rosé.** Pink paper `#FBE9EF`, ink `#3B0B20`, accent `#C2185B`, muted `#93667A`, hairlines `rgba(59,11,32,.15)`. Fraunces (serif) for numbers, headings and buttons; Instrument Sans for body text. One light theme only, no dark variant. A single centred column (max 560px) at every width; the front page fits one phone screen.
